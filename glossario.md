# 📖 Glossário

| Termo | O que significa |
|---|---|
| **Alias** | Apelido para um comando maior. Ex.: `git s` para `git status -s` |
| **Branch** | Linha do tempo paralela do projeto, para trabalhar sem afetar a principal |
| **Checkout / Switch** | Trocar de branch (`git switch` é a forma moderna) |
| **CI (Integração Contínua)** | Robôs que testam o código automaticamente a cada PR |
| **Clone** | Baixar um repositório do GitHub com todo o histórico |
| **Commit** | Uma "foto" do projeto num momento, com mensagem, autor e data |
| **Conflito** | Quando duas mudanças mexem na mesma linha e o Git precisa que você escolha |
| **Diff** | A diferença entre duas versões, linha por linha |
| **Fetch** | Baixar novidades do remoto sem mexer nos seus arquivos |
| **Fork** | Cópia de um repositório de outra pessoa na sua conta do GitHub |
| **GitHub Actions** | Automações do GitHub, como o check que valida o seu JSON |
| **HEAD** | Ponteiro que indica "onde você está agora" (geralmente o último commit da branch atual) |
| **Issue** | Um tópico no GitHub para relatar bug, sugerir ideia ou discutir uma tarefa |
| **main** | Nome da branch principal (em projetos antigos: `master`) |
| **Merge** | Juntar uma branch em outra |
| **origin** | Nome padrão do remoto de onde você clonou (no fluxo de fork, é o **seu** fork) |
| **Pull** | Buscar novidades do remoto e juntar com o seu trabalho (`fetch` + `merge`) |
| **Pull Request (PR)** | Pedido para juntar as suas mudanças num projeto, com revisão |
| **Push** | Enviar seus commits para o remoto |
| **Rebase** | Reaplicar seus commits em cima de outra base, deixando o histórico linear |
| **Remote (remoto)** | Cópia do repositório em outro lugar, geralmente no GitHub |
| **Repositório (repo)** | A pasta do projeto com todo o histórico do Git |
| **Review (revisão)** | Quando alguém lê o seu PR e aprova ou sugere mudanças |
| **SSH** | Forma segura de autenticar no GitHub usando um par de chaves |
| **Staging (área de preparo)** | Onde ficam as mudanças escolhidas para o próximo commit (`git add`) |
| **Stash** | "Gaveta" para guardar mudanças temporariamente sem commitar |
| **Tag** | Etiqueta fixa num commit, usada para marcar versões |
| **Untracked** | Arquivo novo que o Git ainda não está acompanhando |
| **upstream** | No fluxo de fork, o repositório **original** da organização |
| **.gitignore** | Arquivo que lista o que o Git deve ignorar |

## 👋 Boas-vindas

Se você chegou aqui, já deu o passo mais difícil: começar.

Este repositório é uma trilha de estudos. Cada arquivo é uma etapa curta, escrita para quem **nunca** usou Git, sem pressa e sem termos jogados no ar. Ao final, você vai conseguir participar dos projetos da comunidade como qualquer dev profissional: copiando o projeto, criando sua versão, salvando suas mudanças e pedindo para elas entrarem no projeto oficial.

> 🎯 **Objetivo final:** fazer o [Desafio do 1º PR](https://onboarding.unidunedev.workers.dev/desafio-pr) e colocar seu card no [Mural da galera](https://onboarding.unidunedev.workers.dev/mural).

## 🗺️ A trilha

Siga na ordem. Cada etapa termina com um **✅ Checkpoint** para você conferir se deu tudo certo.

| # | Etapa | O que você aprende | Tempo |

| 0 | [O que é Git e GitHub?](00-o-que-e-git-e-github.md) | A ideia por trás de tudo, sem comandos | 10 min |
| 1 | Instalação: [Windows](01-instalacao/windows.md) · [Mac](01-instalacao/mac.md) | Colocar o Git no seu computador | 10 min |

> 🔐 **E o login no GitHub?** Não precisa configurar nada agora. No primeiro `git push`, o Git abre o navegador para você entrar na sua conta e guarda o acesso.

## 🤖 E a IA?

Pode usar, mas do jeito certo:

- ✅ **Use para entender:** "o que significa esse erro?", "por que esse comando existe?"
- ✅ **Use para conferir:** depois de tentar sozinho, peça para revisar o que você fez.
- ❌ **Não use para pular etapas:** colar comandos sem entender é o caminho mais rápido para travar no primeiro problema real.

Em cada etapa existe um **🧠 Desafio sem IA**. Tente resolvê-lo só com o que você aprendeu. Errar faz parte, e é aí que o aprendizado fixa.

## 🤝 Achou um erro? Quer melhorar algo?

Ótimo, esse pode ser **o seu primeiro PR**! Um erro de digitação, um print desatualizado, uma explicação que ficou confusa: tudo vale. Veja o [CONTRIBUTING.md](CONTRIBUTING.md).

Pergunte no grupo da comunidade. Ninguém aqui nasceu sabendo, e toda dúvida ajuda a melhorar este guia.

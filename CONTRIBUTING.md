# Como contribuir com este guia

Que bom que você quer ajudar! Este repositório é ótimo para o seu **primeiro PR**.

## O que vale contribuir

- ✏️ Corrigir erros de digitação ou português
- 💡 Explicar melhor algo que ficou confuso para você
- 🖼️ Adicionar prints de telas (coloque em `imagens/`)
- 🧩 Adicionar uma dica, um erro comum ou um desafio novo
- 🐧 Escrever instruções para Linux

## Como fazer

Siga o [guia de Fork e Pull Request](07-fork-e-pull-request.md), trocando o repositório `onboarding` por `comece-por-aqui`. Em resumo:

1. Faça um **fork** deste repositório.
2. Crie uma branch: `git switch -c docs/descricao-curta`.
3. Faça a mudança e o commit: `git commit -m "docs: corrige comando no guia de SSH"`.
4. `git push -u origin docs/descricao-curta`.
5. Abra o **Pull Request**.

Mudança pequena? Dá para fazer direto pelo navegador: abra o arquivo no GitHub e clique no ícone de lápis ✏️.

## Estilo de escrita

- Português simples, frases curtas, como se explicasse para um colega.
- Toda palavra técnica nova é explicada na primeira vez (e entra no [glossário](glossario.md)).
- Comandos sempre em blocos de código, com a indicação de Windows ou Mac quando forem diferentes.
- Cada guia termina com **✅ Checkpoint** e **🧠 Desafio sem IA**.
